# What is the one definition rule

(One Definition Rule) which states that Only one definition of any variable, function, class type, enumeration type, [concept](https://en.cppreference.com/cpp/language/constraints "cpp/language/constraints") (since C++20) or template is allowed in any one translation unit. Some of these may have multiple declarations, but only one definition is allowed.
